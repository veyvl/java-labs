# Лабораторная работа 2. Классы и инкапсуляция

Вариант: инженерия систем искусственного интеллекта (DataSample).

## Инварианты BankAccount

- Баланс никогда не бывает отрицательным.
- Пополнение и списание принимают только положительную сумму.
- Нельзя списать больше, чем есть на счёте.
- Баланс меняется только через deposit и withdraw, setter отсутствует.

## Инварианты DataSample

- id не равен null и не пуст (строка из одних пробелов тоже считается пустой).
- label не равен null и не пуст.
- features не равен null, содержит хотя бы один элемент, все значения конечные (не NaN и не бесконечность).
- status никогда не равен null; новое наблюдение создаётся в статусе NEW.
- id, label и ссылка на массив признаков неизменяемы после создания (final).
- Массив признаков копируется в конструкторе и при возврате из getFeatures, поэтому внешний код не может изменить признаки объекта.
- Статус меняется только через changeStatus.
- Наблюдение считается готовым тогда и только тогда, когда его статус READY.
